AgentDraw Pass — Deploy Console (Owner)

The NFT companion to AgentDraw · BNB Smart Chain (chainId 56) · This page is the owner's tool — it is not linked from the public site.

01 — Connect owner wallet

Connect the wallet that will own the Pass contract. The page switches it to BNB Smart Chain automatically. The connected wallet becomes owner at deployment: it can open/close the mint, pause mints, set the base URI (only before the first mint) and withdraw the owner half of Founder mints. It can never touch the half that goes to the check-in pool — that half leaves inside the mint transaction itself.

Not connected.

02 — Deploy AgentDrawPass

Deploys the Pass NFT (ERC-721, AgentDraw Pass / ADPASS). Both constructor arguments are prefilled with the live mainnet contracts and guarded — do not change them. The economics are constants in the code and can never change: Player Pass free (IDs 1–2222, needs an Agent ID + 1 check-in point), Founder Pass exactly 0.001 BNB (IDs 5001–5500), of which 0.0005 BNB goes to the check-in pool and 0.0005 BNB to the owner balance, enforced inside every mint.

⚠️ This is NOT the official Binance Agent ID registry (0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F). Double-check before deploying — a wrong registry means the mint gate checks the wrong NFT, and constructor arguments cannot be changed afterwards.
⚠️ This is NOT the live AgentDrawCheckIn companion (0xFc814Fd5a98C430aACdd78d150D157A5421b761e). With a wrong address the points gate reads the wrong contract and the Founder pool share would be sent to the wrong place. Constructor arguments cannot be changed afterwards.

03 — Set the metadata base URI

Points tokenURI at the published metadata (baseURI + tokenId + ".json"). The artwork and JSON for all 2,722 passes are already generated and pushed under /pass/metadata/. Do this before opening the mint: the base URI locks forever at the first mint of either lane and can never be repointed afterwards.

04 — Open the mint

The mint starts closed. Open it only after the base URI is set (step 03) and the metadata is live. Both lanes open together, in parallel — the paid lane is never gated behind the free lane. Pause is an emergency brake for mints only; transfers and withdrawals keep working while paused.

05 — State, withdraw + summary

Live state of the Pass contract. The owner balance is exactly the owner half of Founder mints (the pool half already left at mint time — it is not here and cannot be withdrawn). Then copy the summary box and send it to Muse to wire the Pass section into the public site and the ClawHub skill.
