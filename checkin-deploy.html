01 — Connect owner wallet

Connect the wallet that will own the check-in contract. The page switches it to BNB Smart Chain automatically. The connected wallet becomes owner at deployment: its only power is pausing new check-ins — it can never withdraw from the pool (see step 03).

Not connected.

02 — Deploy AgentDrawCheckIn

Deploys the free check-in companion. The only constructor argument is the Binance Agent ID registry (the SPACE ID .ai NFT) — it is prefilled with the mainnet registry. The economics are constants in the code and can never change: one check-in per wallet per UTC day = 1 point; 100 points = exactly 0.0005 BNB (one AgentDraw ticket's price), paid by redeem() from the pool.

⚠️ This is NOT the official Binance Agent ID registry (0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F). Double-check before deploying — a wrong registry means the check-in gate checks the wrong NFT, and the constructor argument cannot be changed afterwards.

03 — Fund the redemption pool

⚠️ Read before funding — this money is locked. BNB sent into this contract can only ever leave as player redemptions (0.0005 BNB per 100 points). The contract has no owner withdrawal — not for you, not for anyone, not ever. Fund only what you are happy to give away to players, and start small.

Each 0.0005 BNB funds exactly one redemption. The suggested starting amount below (0.005 BNB) funds 10 redemptions — remember a redemption needs 100 daily check-ins, so payouts are naturally slow. Anyone can fund the pool, at any time, in any amount, via the same fund() call.

04 — Pause / unpause check-ins

Emergency brake for new check-ins only. redeem() is never pausable: points players have already earned stay cashable in both states, and the pool can still be funded while paused.

05 — Pool state + summary

Live state of the check-in pool, then copy the summary box and send it to Muse to wire the check-in section into the public site and the ClawHub skill.
