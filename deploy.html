AgentDraw — Deploy Console (Owner)

Daily on-chain draw for Binance Agent ID holders · BNB Smart Chain (chainId 56) · This page is the owner's tool — it is not linked from the public site.

01 — Connect owner wallet

Connect the wallet that will own the contract. The page switches it to BNB Smart Chain automatically. The connected wallet becomes owner at deployment: it collects the 35% entry fees and can pause entries.

Not connected.

02 — Deploy AgentDraw

Deploys the draw contract. The only constructor argument is the Binance Agent ID registry (the SPACE ID .ai NFT) — it is prefilled with the mainnet registry. The ticket price (0.0005 BNB) and the 65/35 split are constants in the code and can never change after deployment.

⚠️ This is NOT the official Binance Agent ID registry (0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F). Double-check before deploying — a wrong registry means the Agent ID entry gate checks the wrong NFT, and the constructor argument cannot be changed afterwards.

03 — Pause / unpause entries

Emergency brake for ticket sales only. Settling finished days and the prize pools are never affected by the pause.

04 — Settle the oldest unsettled day

Permissionless in principle (anyone can call it), included here for convenience. Settles one finished day per call: draws the winning ticket and pays the winner 100% of that day's prize pool. Reverts with "Day not ended" while the oldest unsettled day is still running.

05 — Withdraw fees + summary

Withdraws the owner balance: the accumulated 35% entry fees (credited instantly at every entry, withdrawable at any time). Prize pools are never part of this balance and can never be withdrawn. Then copy the summary box and send it to Muse to wire the public site.
